## Hypothesis

AGI begins as governed augmentation, not a remote platform.

## Problem

Most knowledge work is scattered across chats, tabs, documents, private app state, and temporary model context. The worker remembers the workflow, the tool forgets it, and every new session starts by reconstructing state.

## Solution served by koad:io

koad:io externalizes cognition into named filesystem objects: commands for procedures, memories for durable context, skills for reusable behavior, entities for roles, and briefs for directed work.

## Technical model

- Entity directory.
- Command cascade.
- Harness session.
- Git-backed evolution.

## Install / setup path

1. Install koad:io on hardware you control.
2. Create one entity for your operating role.
3. Move repeated workflows into commands.
4. Move durable knowledge into memories and skills.
5. Commit changes so the substrate has history.

## Verification

A new session should recover role, context, tools, and reusable procedures without reconstructing them from scratch.
