## Hypothesis

Intelligence needs an operating structure before it needs more prompts.

## Problem

Large language models are strong inference engines with weak continuity. They do not naturally maintain identity, authority, memory, or operational boundaries across sessions.

## Solution served by koad:io

koad:io makes the cognitive structure explicit. Each entity is a role-bound subsystem with identity, memory, skills, commands, trust bonds, and history.

## Technical model

- Identity in `ENTITY.md`.
- Memory in markdown records.
- Skills as reusable behavior.
- Commands as motor action.
- Trust bonds as governance.
- Sessions as attention.

## Install / setup path

1. Define the first entity's role.
2. Add memories and skills.
3. Create commands for repeatable actions.
4. Use trust bonds for delegation.
5. Run work through harness sessions.

## Verification

The entity should refuse out-of-scope work, recall relevant context, and leave an auditable trace.
