## Hypothesis

A session is the moment an entity becomes operational.

## Problem

An entity is not useful until identity, role, memory, tools, model runtime, and workspace context are assembled into one active work surface.

## Solution served by koad:io

The harness loads the constitution, role primers, skills, workspace context, tool policy, and prompt into a bounded session.

## Technical model

- Startup context assembly.
- Tool visibility through bond gate.
- Model/provider defaults through environment cascade.
- Session artifacts for audit and recall.

## Install / setup path

1. Set default harness/provider/model.
2. Invoke the entity.
3. Confirm identity, cwd, tools, and context appear in the session.

## Verification

A fresh session should wake up with the right self and place.
